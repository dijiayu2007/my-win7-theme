# 我的 Win7 定制版 Hexo 主题

这是一个基于原版 Win7 拟物化主题进行深度定制的版本，新增了相册、可拖拽日历等互动组件。

感谢原作者的开源精神，让我有了在此基础上继续调整的空间。

## 我的更改与新增记录
在保留原版核心风格的前提下，我主要做了以下调整：
1. **新增相册页面**：做了一个 5 列自适应的相册墙，点击图片会弹出一个支持拖拽的查看器，可附带介绍或跳转链接。
2. **调整浮窗逻辑**：将原本默认悬挂的附件浮窗移到了左侧导航栏中触发。新增了带农历的日历时钟浮窗。两者均支持电脑鼠标和手机触屏拖拽。
3. **优化页面滚动**：调整了布局，右侧文章区域独立滚动，左侧导航栏和窗口框架保持固定。
4. **新增社交图标**：补充了 X 和 Instagram 的跳转链接及对应图标。

# 以下为完整的安装与使用文档（基于原版说明）

一个 **Windows 7 / Frutiger Aero** 玻璃拟态风格的 Hexo 主题。

把博客做成一个「Windows 资源管理器窗口」：Aero 玻璃标题栏、银色立体窗框、资源管理器式的文章列表（名称 / 修改日期 / 摘要三列）、面包屑地址栏、自定义右键菜单、可拖拽的音乐播放器与附件浮窗、全屏加载动画。

> 特点：**全站资源本地化**——CSS / JS / 图片 / 图标 / 字体 / MathJax / 代码高亮全部内置，不请求任何外部 CDN，国内访问无超时。
> （唯一的可选外部依赖是 Twikoo 评论后端，需你自己部署，见下文；不配则不出现评论。）

---

## 一、环境要求

- Node.js 18+（建议 20）
- Hexo 7.x

---

## 二、安装步骤

### 1. 放入主题
把整个 `win7` 文件夹放到你的博客的 `themes/` 目录下，即 `themes/win7/`。

### 2. 安装依赖插件（重要！不装会构建报错）
本主题用到以下 Hexo 插件，在博客根目录执行：

```bash
npm install hexo-abbrlink hexo-generator-tag hexo-generator-feed hexo-generator-sitemap hexo-renderer-ejs --save
